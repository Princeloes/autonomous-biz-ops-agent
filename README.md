# Autonomous Business Operations Agent

This is an Autonomous Business Operations Agent (AI Employee) built for Enterprise Automation.

## Technologies Used
- **LangGraph**: For multi-agent orchestration.
- **FastAPI**: Backend web framework.
- **Model Context Protocol (MCP)**: For connecting to external tools.
- **Mem0**: Personalization and memory.
- **Langfuse**: Observability and evaluation.
- **Playwright**: Browser automation.
